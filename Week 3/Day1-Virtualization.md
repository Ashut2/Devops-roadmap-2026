## What is Virtual Machine
- It is the logical separation of the server by hypervisor to efficiently create virtual computer systems.
- Famous Hypervisor example : VMware , Xen etc

### Eg : 
suppose you requested the ec2 Instance(Common term in Amazon for virtual machine) from AWS , So what would AWS do - will direct the request to hypervisor
, that will create logical sepration within the server and then it will give you the details of the VM to access it like IP Address and Key-value pairs etc.

You can't demand the physical access of the VM even if you are paying for it.

This concept of virtualization made the efficient use of the server possible.
