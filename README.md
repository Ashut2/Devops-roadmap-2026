# Devops-roadmap-2026

## Goal
Paid Devops Internship
## Timeline
10 weeks
## phase list
 ### Phase 1
: Foundations (Weeks 1-3)
Master Linux/CLI (critical for 90% roles) and deepen Git/Docker. Learn Bash scripting via free KodeKloud labs (Linux basics, shell). Practice: Set up Ubuntu VM, automate Git workflows, Dockerize a Python app.

Daily: 30min Linux commands (file mgmt, processes).

Milestone: GitHub repo with 3 Docker containers (e.g., Python app).
​
 ### phase 2
 Phase 2: Core Tools (Weeks 4-7)
 CI/CD (Jenkins/GitHub Actions), IaC (Ansible/Terraform basics), intro Kubernetes. Use free resources: KodeKloud emails, YouTube (Tech Monk DevOps course). Practice: Build CI/CD pipeline deploying Docker app to  local K8s (Minikube).
​

 Skip cloud-heavy till basics solid.

 Milestone: GitHub Actions pipeline for auto-deploy.
​
 ### Phase 3
 Phase 3: Cloud & Advanced (Weeks 8-10)
 AWS free tier: EC2, IAM, S3. Add monitoring (Prometheus basics). Practice: Deploy full stack (e.g., Node app) on AWS via Terraform.

 Milestone: AWS-hosted project with CI/CD.

## Projects Portfolio
Build 5 GitHub repos (key for tier-3 resumes): 1) Dockerized todo app with CI/CD. 2) Ansible for server config. 3) K8s cluster (Minikube). 4) AWS static site deploy. 5) Monitoring dashboard. Fork from GitHub ideas, customize.
